# Battle Cats local assets

This folder stores game-screen images and actual Battle Cats Wiki assets locally so the game does not rely on external image hosts.

## Main menu images

- title-screen.webp — local copy of the title-screen reference used for the opening screen.
- cat-base-reference.jpg — an alternate Cat Base screenshot used only as a fallback.

## Wiki images / spritesheets

- original_sheets/cat-base-menu.webp — Cat Base menu reference with the authentic button positions and character.
- original_sheets/main-menu-ver-10-10.webp — alternative main-menu screenshot.
- original_sheets/normal-cat-right-icon.webp — a real Cat icon from the wiki.
- original_sheets/cat-base-menu-icon.webp — Cat Base menu icon.
- original_sheets/cat-base-accessory-icon.webp — Cat Base accessory icon.
- original_sheets/basic-cat-bcp.webp, basic-cat-e-bcp.webp, basic-cat-tf-bcp.webp — Basic Cat-related source images from the wiki.
- original_sheets/index.json — source links and asset notes for imported wiki images.

The source metadata is tracked in original_sheets/index.json. Community wiki images are generally marked CC BY-SA unless a file's page states otherwise; the original game art belongs to its respective rights holders.
