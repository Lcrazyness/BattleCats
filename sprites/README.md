# Sprites

All reusable game artwork should live in this folder so pages use local assets, not external image hosts.

- title-background.svg — sunset scenery and distant architecture.
- title-logo.svg — outlined title logo and cat mascot.
- title-crowd.svg — cat crowd along the title screen's bottom edge.
- cat.svg — full-body Cat for Cat Base.
- cat-head.svg — reusable Cat head icon.
- mailbox.svg — local mailbox icon.

SVGs are editable source images. Reference them with relative paths such as sprites/cat.svg.
